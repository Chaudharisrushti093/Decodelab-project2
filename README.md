# Decodelab-project2
🚀 Project 2 – 

Cloud Computing – DecodeLabs Industrial Training

---
🎯 Project Objective

The objective of this project is to provision and configure a cloud-based virtual server and host a custom webpage using basic cloud computing and system administration skills.

---

## In this project:

- Launched a Linux-based virtual machine using AWS EC2.
- Configured the required security and network access.
- Connected to the server securely using SSH.
- Installed and configured the Apache web server.
- Created and hosted a custom "Welcome to DecodeLabs" webpage.
- Verified that the webpage was accessible through the server's public IP address.

## 🛠️ Technologies & Tools

- Cloud Platform: AWS EC2
- Operating System: Linux
- Web Server: Apache
- Connection: SSH
- Terminal: Command Line
- Browser: Web Browser

---

## 🔧 Project Workflow

1. Created and launched a Linux-based AWS EC2 instance.
2. Configured the required Security Group rules.
3. Connected to the EC2 instance using SSH.
4. Installed the Apache web server.
5. Created a custom welcome webpage.
6. Started and configured the Apache web server.
7. Accessed the webpage using the EC2 public IP address.
8. Verified that the webpage was successfully hosted and accessible.

---

## 🌐 Expected Result

The deployed AWS EC2 server successfully displays a custom webpage containing the message:

"Welcome to DecodeLabs"

The webpage is accessible through the public IP address of the EC2 instance.
