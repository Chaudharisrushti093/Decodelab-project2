# Decodelab-project2
Project 2 – The Server Commander 🚀
Cloud Computing (AWS/Azure) – DecodeLabs
This project is part of the DecodeLabs Cloud Computing Industrial Training Kit (Project 2). The objective is to provision and configure a virtual server and host a custom webpage using system administration skills.
🎯 Project Objective
Act as a Cloud/System Administrator and:
Launch a virtual machine using AWS EC2 / Azure Virtual Machine
Use a Linux operating system such as Ubuntu or Amazon Linux
Connect securely to the server using SSH
Install a web server such as Apache or Nginx
Host a custom "Welcome to DecodeLabs" webpage
Verify that the webpage is accessible through the server
🛠️ Technologies & Tools
Cloud Platform: AWS EC2 / Azure Virtual Machine
Operating System: Linux (Ubuntu / Amazon Linux)
Web Server: Apache / Nginx
Connection: SSH
Terminal / Command Line
🔧 Project Workflow
Create and launch a Linux-based virtual machine.
Configure the required security/network access.
Connect to the virtual machine using SSH.
Install and configure Apache or Nginx.
Create the custom welcome webpage.
Start/enable the web server.
Access the server using its public IP address and verify the webpage.
🌐 Expected Result
The deployed virtual server should successfully display a custom webpage with a "Welcome to DecodeLabs" message when accessed through the server's public address.
